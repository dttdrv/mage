- [perf-goldmines.md](perf-goldmines.md) — Consolidated deep-research on universal CPU-side performance gold mines for the mage stack (Wine 11.13 wow64 under Rosetta 2, DOOM 2016 baseline 73 FPS CPU-bound). Round 1 (2026-07-20): alternative x86→arm64 engines & hybrid architectures; graphics-boundary architectures (gfxstream render server, Venus); Wine sync/IPC state of the art (inproc_sync/msync/WFUSync); measurement techniques for Rosetta-translated processes. Each round ends with a ranked gold-mines table; the Round 2 ranking supersedes Round 1.
- [cef-crossprocess-present.md](cef-crossprocess-present.md) — Why Steam (any CEF app) is a black window on mainline Wine/macOS even with `-cef-disable-gpu`: chrome-runtime forces GPU compositing into a separate process and cross-process present is unimplemented upstream (a CrossOver-vs-mainline boundary). Structural fix = IOSurface bridge between CEF GPU process (producer, root-HWND-keyed) and winemac.drv (consumer, IOSurfaceIsGlobal + 60 Hz redraw poll). Universal fix for all CEF launchers; on the roadmap, game unaffected.
